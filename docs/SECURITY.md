# 보안과 데이터 경계

숫자 추첨은 브라우저에서만 실행합니다. API·인증·베팅·결제·지갑·외부 결과 인증 기능은 없습니다. 참가자 개인명이나 가짜 사용자·랭킹·후기 데이터가 포함되지 않습니다.

RNG는 Web Crypto Uint32와 rejection sampling을 사용합니다. 유효한 정수 상한과 helper의 자원 제한을 검사합니다. 중복 비허용은 남은 pool에서 선택합니다. 사용자의 브라우저를 통제하거나 외부 공정성 감사를 제공하는 기능이 아닙니다.

입력은 React text로 렌더링하며 HTML로 실행하지 않습니다. 잘못된 수치 draft는 한국어 오류로 표시하고 추첨을 막습니다. Web Crypto·Canvas 오류는 각각 toast·fallback으로 처리합니다.

설정과 결과는 React 메모리 상태입니다. 새로고침하면 초기화됩니다. production에서 로그를 browser storage에 자동 저장하거나 네트워크로 전송하지 않습니다. 개발 모드의 console 진단은 local 개발 도구에만 표시합니다. 오류 화면은 새로고침 동작만 제공하고 stack·URL·기기 정보를 외부 사이트에 첨부하지 않습니다.

`npm audit`와 Gitleaks는 확인 시점의 의존성·소스 검사입니다. 이 결과를 모든 취약점 부재나 미래 버전의 보장으로 표현하지 않습니다. static host의 보안 헤더는 해당 host에서 실제 적용을 별도로 확인해야 합니다.
